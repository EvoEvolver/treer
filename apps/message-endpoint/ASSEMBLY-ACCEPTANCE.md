## Reproduce

From the checkout root (Cargo cache/dependencies already installed):

```sh
cargo test --manifest-path apps/message-endpoint/Cargo.toml --locked --offline --all-features hub_runtime::positive_fixture -- --nocapture
cargo test --manifest-path apps/message-endpoint/Cargo.toml --locked --offline --all-features owner_configuration_inspects -- --nocapture
cargo test --manifest-path apps/message-endpoint/Cargo.toml --locked --offline --all-features uncertainty_capacity -- --nocapture
cargo test --manifest-path apps/message-endpoint/Cargo.toml --locked --offline --all-features telegram_cutoff -- --nocapture
python3 -B -m unittest discover -s apps/message-endpoint/tests -p test_migration_plan.py
npm --prefix apps/message-endpoint run check
cargo check --manifest-path apps/message-endpoint/Cargo.toml --locked --offline --no-default-features
cargo clippy --manifest-path apps/message-endpoint/Cargo.toml --locked --offline --all-features --all-targets -- -D warnings
```

The checked-in UI assets are rebuilt with `npm --prefix apps/message-endpoint
run build:ui`. Native browser entry:

```sh
cargo build --manifest-path apps/message-endpoint/Cargo.toml --locked --offline --features hub --bin treer-message-hub
node apps/message-endpoint/tests/email-browser.mjs /absolute/path/to/treer-message-hub /absolute/path/to/playwright-core /absolute/path/to/browser-cache /absolute/private/screenshots
```

The browser executable path must match the Cargo target directory selected by
the caller. The fixture kills/joins its own children and removes its temporary
state; runtime test Drop guards join the native runtime and synthetic poller.
No listener or test process is intentionally retained.
